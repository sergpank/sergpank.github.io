## Configure Xray in Docker

1. Generate UUID and Reality keypair:
```bash
docker run --rm ghcr.io/xtls/xray-core:latest uuid
docker run --rm ghcr.io/xtls/xray-core:latest x25519
```
`PrivateKey` goes into `config.json`, `Password (PublicKey)` goes into the client link. `Hash32` is not used.

2. Create `docker-compose.yml`:
```yml
services:
  xray:
    image: ghcr.io/xtls/xray-core:latest
    container_name: xray
    restart: always
    network_mode: host
    user: root # <--- important
    cap_add:
      - NET_BIND_SERVICE # <--- to take ports lower 1024
    volumes:
      - ./config.json:/usr/local/etc/xray/config.json
```

3. Create `config.json` — insert UUID and PrivateKey from step 1
```json
{
  "inbounds": [{
    "port": 443,
    "listen": "0.0.0.0",
    "protocol": "vless",
    "settings": {
      "clients": [{
        "id": "... UUID ...",
        "flow": "xtls-rprx-vision"
      }],
      "decryption": "none"
    },
    "streamSettings": {
      "network": "tcp",
      "security": "reality",
      "realitySettings": {
        "show": false,
        "dest": "google.com:443",
        "serverNames": ["google.com"],
        "privateKey": "... private key ...",
        "shortIds": [""]
      }
    }
  }],
  "outbounds": [{
    "protocol": "freedom"
  }]
}
```

4. Start Docker:
```bash
docker compose up -d
docker compose logs -f xray
```
Look for `Xray ... started`. 

5. Create VLESS link (in one line, + you may need to change SNI):
```text
vless://[YOUR_UUID]@[YOUR_DDNS_DOMAIN_OR_IP]:443
?flow=xtls-rprx-vision
&security=reality
&encryption=none
&type=tcp
&sni=google.com
&fp=chrome
&pbk=[YOUR_PUBLIC_KEY]#TestVPN
```

6. Import this link into V2BOX or other client.

## Rotating keys / revoking access

1. Generate UUID and KEY and update `config.json`:
```bash
docker compose exec xray xray uuid
... UUID ...

# UUID update is enough if you need to revoke access from the user
# generate new reality only if private key was leaked

docker compose exec xray xray x25519
PrivateKey: ... private key ...
Password (PublicKey): ... public key ...
Hash32: ... hash ...
```

2. Restart Docker:
```bash
docker compose down
docker compose up -d --force-recreate
```
After editing `config.json`, use `docker compose up -d --force-recreate`.
A plain `restart` may keep the old file, since it is bind-mounted by inode.
